## Problem Statement

This project is a Discount Price Calculator developed using Java Servlets.  
The user enters the product name, original price, and discount percentage in an HTML form.  
The Servlet processes the request using doPost() and calculates the discount amount and final discounted price, then displays the result to the user.

## How to Run This Project

1. Clone this repository or download the ZIP.
2. Import the project into Eclipse as a Dynamic Web Project.
3. Configure Apache Tomcat 10.1 server in Eclipse.
4. Right-click project → Run As → Run on Server.
5. Open browser and go to:

```text
http://localhost:8080/DiscountCalculator/index.html
